# gallery-with-sass

Galeria de imagens construída com Sass para praticar mixins e organização de estilos.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `css/styles.css`.

**Tecnologias:** `CSS`, `HTML`, `Sass`.
